# Микросимуляция транспортного потока — первая итерация

## Назначение

Модуль запускает детерминированный расчёт по связям «въездная полоса → выездная полоса» с учётом действующего циклического плана светофора. Результат включает временные снимки для визуального воспроизведения, очереди и агрегированные показатели.

## Ввод интенсивности

Для каждого разрешённого движения задаётся:
- общая интенсивность, авт./ч;
- специальная интенсивность по каждому классу ТС, авт./ч.

Специальные значения являются частью общей интенсивности, а не добавляются поверх неё. Сумма специальных интенсивностей не может превышать общую. Разность считается нераспределённым потоком; он участвует в очереди и выпуске как условный легковой автомобиль, но в отчёте остаётся отдельной категорией «Не распределено».

Поддерживаются классы из каталога VehicleClass: легковые, малотоннажные, грузовые, автопоезда, автобусы, сочленённые автобусы, троллейбусы, сочленённые троллейбусы, мотоциклы и велосипеды.

## Принцип расчёта

1. Прибытия каждого класса формируются равномерно с интервалом 3600 / интенсивность.
2. Очередь ведётся отдельно для каждой связи полос.
3. Выпуск из очереди разрешён только в зелёное окно той фазы, которой назначена связь.
4. Временные окна фаз и длина цикла берутся из SignalPlanTimingAnalyzer. Жёлтый и общий красный интервалы не считаются зелёным временем.
5. Интервал выпуска учитывает длину условной модели ТС: 1,8 + длина / 35 секунд.
6. После пересечения стоп-линии ТС проходит движение с расчётной скоростью, ограниченной 30 км/ч и максимальной скоростью модели.
7. Снимки состояния сохраняются с секундным шагом для анимации.

## Показатели

- поступившие ТС;
- выпущенные через стоп-линию ТС;
- остаточная и максимальная очередь;
- средняя накопленная задержка всех прибывших ТС, включая оставшиеся в очереди к концу расчёта;
- суммарная накопленная задержка в авт.-ч, включая ожидание ТС в остаточной очереди;
- фактическая часовая интенсивность выпуска;
- те же показатели по категориям и движениям.

## Ограничения первой итерации

Это детерминированная упрощённая модель очередей, а не калиброванная модель следования за лидером. В ней пока отсутствуют перестроения, смена полос, блокирование перекрёстка выехавшими ТС, пешеходные фазы, приоритет общественного транспорта, случайные распределения интервалов, ускорение/торможение на подходе, насыщенный поток по нормативным методикам и калибровка по натурным наблюдениям. Расчётные значения нельзя использовать как официальное заключение о пропускной способности без последующей верификации.
