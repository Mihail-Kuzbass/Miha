# Спринт №1 — Android foundation

## Цель
Получить Android-проект, который открывается в Android Studio, собирает debug APK, создаёт локальный проект с шаблонным четырёхсторонним перекрёстком, сохраняет его и позволяет повторно открыть.

## Объём
1. Gradle multi-module проект.
2. Kotlin + Jetpack Compose.
3. Android API 29+.
4. Доменная модель проекта и дорожной сети.
5. Шаблоны четырёхстороннего и Т-образного перекрёстка.
6. Локальное JSON-хранилище в приватной папке приложения.
7. Главное меню со списком последних проектов.
8. Первый экран редактора со схематичным видом сверху.
9. Unit-тесты доменной модели и генератора шаблонов.

## Не входит
Ручное изменение геометрии на Canvas, расчёт конфликтов, светофорные фазы, микросимуляция, координация, импорт OSM/2ГИС и нормативное заключение.

## Версии
AGP 9.5.0; Gradle 9.7.0; Kotlin 2.4.20 для чистых JVM-модулей и Compose Compiler; Compose BOM 2026.09.00; compileSdk 37; targetSdk 36; minSdk 29; Java 17. Android-модули используют встроенную поддержку Kotlin в AGP 9.x. Версии зафиксированы в version catalog и должны быть проверены локальным Gradle Sync.

## Критерии приёмки
- [ ] Gradle Sync без ошибок.
- [ ] `assembleDebug` создаёт APK.
- [ ] APK устанавливается на Android 10/API 29 и выше.
- [ ] Приложение запускается без сети.
- [ ] Главное меню отображается на смартфоне.
- [ ] Создание проекта добавляет шаблонный перекрёсток.
- [ ] Проект сохраняется локально и остаётся в списке после перезапуска.
- [ ] Проект открывается в редакторе.
- [ ] Unit-тесты модели и шаблонов проходят.
- [ ] Нет обязательной зависимости от SUMO, 2ГИС или сетевого сервиса.

## Команды
```bash
gradle :core:model:test
gradle :core:geometry:test
gradle :app:assembleDebug
gradle :app:testDebugUnitTest
```

## Ограничения заготовки
Редактор пока только визуализирует схему; это не полноценный CAD. JSON-хранилищу нужна миграционная стратегия при изменении схемы. APK ещё должен быть собран и проверен в Android Studio или CI.
