# Интеграция Eclipse SUMO (этап 1)

В ветке `feature/sumo-integration` добавлен отдельный адаптер для запуска SUMO как внешнего симулятора.

- Обнаружение `sumo` и `netconvert` через указанный каталог, `SUMO_HOME` или `PATH`.
- Запуск сценария по готовым файлам сети `.net.xml` и маршрутов `.rou.xml`.
- Сбор числа завершивших поездку автомобилей, средней длительности поездки и среднего времени ожидания из `tripinfo.xml`.
- SUMO не поставляется вместе с приложением; пользователь устанавливает его отдельно.

Это первый этап. Адаптер пока не связан с редактором фаз и полос TrafficSignalStudio; для этого нужна отдельная UI-интеграция и отображение/сопоставление сигналов с контролируемыми связями SUMO.
